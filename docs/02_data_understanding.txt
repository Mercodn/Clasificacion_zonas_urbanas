Dataset Name: VIIRS Nighttime Lights - Cundinamarca

Geographic Bounds:

1.10 Data Quality Issues and Resolutions
-----------------------------------------

Issue 1: Radiance Right-Skew
    Problem: Distribution heavily skewed toward low values
    Resolution: Apply log-transformation in Phase 3
    Impact: Improves model learning and interpretation

Issue 2: Class Imbalance
    Problem: More medium-radiance points than high/low
    Resolution: Use stratified cross-validation and class weights
    Impact: Balanced model evaluation

Issue 3: Spatial Autocorrelation
    Problem: Nearby points tend to have similar radiance
    Resolution: Use geographic partitioning in cross-validation
    Impact: More realistic performance estimates

Issue 4: Multicollinearity in NTL Variables
    Problem: ln_mean_NTL and ln_sum_NTL highly correlated (r=0.88)
    Resolution: Select one NTL variable; don't use both in model
    Impact: Reduced redundancy, simpler model

3. DATA CHARACTERISTICS FOR MODELING
================================================================================

3.1 Suitability for Classification
----------------------------------

Radiance Thresholds Identified:
    • Low:   avg_rad ≤ 5
    • Medium: 5 < avg_rad ≤ 15
    • High:   avg_rad > 15

Evidence for Clear Boundaries:
    • Natural gap between 5 and 6 nW/cm²/sr
    • Natural gap between 15 and 16 nW/cm²/sr
    • Reflects ecological and planning-relevant distinctions
    • Aligns with literature on light pollution classification

3.2 Feature Engineering Opportunities
-------------------------------------

Derived Features from avg_rad:
    • log_rad = log(1 + avg_rad): Reduces skewness
    • rad_sq = avg_rad²: Emphasizes extreme values
    • rad_sqrt = sqrt(avg_rad): Inverse of quadratic

Geographic Features:
    • dist_bogota = distance to Bogotá centroid
    • urban_proximity = proximity to known urban centers
    • elevation = approximate elevation (from coordinates)

Composite Features:
    • radiance_zone_density = concentration of high-radiance points nearby

--------------------------------

Challenges:

4. RECOMMENDATIONS FOR DATA ENGINEERING
================================================================================

1. Apply log-transformation to avg_rad
2. Create distance-based features (e.g., dist_bogota)
3. Select dominant NTL variable (ln_mean_NTL preferred over ln_sum_NTL)
4. Use stratified cross-validation by pollution class
5. Consider geographic stratification in train/test split
6. Apply StandardScaler for feature normalization
