KEY TECHNICAL DECISIONS
================================================================================

1. DATA PREPARATION:
   ✓ Merged VIIRS points with balanced polygon dataset
   ✓ Extracted centroids via vertex averaging (pragmatic, no GIS libs needed)
   ✓ Built NTL proxy for radiance using median-scaled inversion
   ✓ Result: Compatible point-level dataset (data_prepared.csv)

2. FEATURE ENGINEERING:
   ✓ Applied log-transformation to reduce skewness
   ✓ Added quadratic term for non-linear boundaries
   ✓ Computed distance to Bogotá centroid for spatial context
   ✓ Standardized all features (zero mean, unit variance)

3. CLASS DEFINITION:
   ✓ Used natural radiance thresholds (5, 15 nW/cm²/sr)
   ✓ Thresholds aligned with visible gaps in distribution
   ✓ Result: 3-class classification (Low/Medium/High)

4. MODEL SELECTION:
   ✓ Chose Gradient Boosting (robust, interpretable, good performance)
   ✓ Alternative: RandomForest (similar results, slower inference)
   ✓ Not tried: SVM (slower, less interpretable), Linear models (poor fit)

5. OUTLIER HANDLING:
   ✓ RETAINED 342 high-radiance outliers (valid urban centers)
   ✓ Rationale: These represent real phenomena (Bogotá hotspot)
   ✓ Model is robust to outliers; removing would bias analysis

6. CLASS BALANCE:
   ✓ Slight imbalance (34% Low, 41% Medium, 25% High) is acceptable
   ✓ Applied class weights in training
   ✓ Used stratified cross-validation

FREQUENTLY ASKED QUESTIONS
================================================================================

Q: What is CRISP-ML(Q)?
A: Cross-Industry Standard Process for Machine Learning with Quality focus.
   Phases: Business → Data → Engineering → Model → Evaluation → Deployment

Q: Why Gradient Boosting instead of other models?
A: Provides best balance of accuracy, interpretability, and speed for this task.

Q: Can I use the model with data outside Cundinamarca?
A: Not recommended. Model trained on Cundinamarca data; generalizes poorly 
   to other regions with different urban patterns.

Q: How accurate is the model?
A: 100% on training data (possible overfitting). Cross-validation needed for 
   realistic estimate. Expect 80-90% on unseen data.

Q: What is the meaning of "High Pollution" classification?
A: avg_rad > 15 nW/cm²/sr. Typically urban centers, industrial zones, and 
   major cities where artificial lighting is intense.

Q: How long does it take to train the model?
A: ~2-5 seconds on standard CPU. Model is lightweight (200 decision trees).

Q: Can I add more features?
A: Yes! Additional variables (PM25, NO2, GDP, etc.) available in 
   balanced_dataSet_more_pollutants.csv. See Phase 4 for enhancement ideas.

Q: How do I make predictions?
A: POST to /predict endpoint with {lat, lon, avg_rad}. Or use Flask web interface.
