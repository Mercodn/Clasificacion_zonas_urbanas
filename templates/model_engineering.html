Training Pipeline Overview

  • Dataset split: 80/20 stratified train/test.
  • Feature set: avg_rad, log_rad, lat, lon, dist_bogota, rad_sq.
  • Scaling: StandardScaler fit on train data.
  • Models trained: Gradient Boosting, Random Forest, Logistic Regression.
  • Model selection criteria: highest test accuracy.

Console Prediction Examples

Use the prediction API or the Python class to get zone outputs.

cURL 
curl -X POST http://localhost:5000/predict \
  -H "Content-Type: application/json" \
  -d '{"lat": 4.711, "lon": -74.072, "avg_rad": 12.3}'
Python 
import requests

response = requests.post(
  "http://localhost:5000/predict",
  json={"lat": 4.711, "lon": -74.072, "avg_rad": 12.3}
)
print(response.json())
