CRISP-ML(Q) Overview

This project follows the CRISP-ML methodology to ensure a structured, repeatable machine learning workflow.

  • Business Understanding: Define problem context, objectives, risks, and expected impact.
  • Data Understanding: Explore dataset structure, quality, and key statistical patterns.
  • Data Engineering: Clean, transform, and prepare features for modeling.
  • Deployment: Publish the Flask application publicly and document the solution.

The application includes dedicated pages for each phase and demonstrates how satellite data can support environmental decision-making.

Phase Structure

The app shows the following main sections:

  1. Home: Overview, heatmap, and prediction interface.
  2. Business Understanding: Problem definition, objectives, questions, feasibility, risks.
  3. Data Understanding: Dataset description, statistics, data quality, spatial insights.
  4. Data Engineering: Feature engineering, scaling, model-ready dataset.

Each page is designed to support the first stages of the machine learning project in English.
