Data Engineering & Modeling

Data preparation, feature engineering, and model training for light pollution classification.

Data Engineering Pipeline

  1. Data Cleaning: Parsed GeoJSON coordinates into lat/lon; validated radiance bounds (0–500 nW/cm²/sr).
  2. Null Handling: No missing values detected; dataset is complete.
  3. Feature Engineering:
    • avg_rad — Raw radiance (primary signal)
    • log_rad — Log-transformed (reduces skewness and outlier impact)
    • dist_bogota — Euclidean distance to Bogotá (geographic context)
    • rad_sq — Squared radiance (captures non-linear intensity effects)
    • lat, lon — Raw coordinates for spatial patterns
  4. Feature Selection: All 6 features retained; no dimensionality reduction applied.
  5. Scaling: StandardScaler normalization (mean=0, std=1) for consistent gradient boosting input.

Zoning Strategy

Zones assigned via radiance thresholds based on Bortle Dark-Sky Scale adaptation for satellites:

  • Zone 0 (Pristine): < 0.20 nW/cm²/sr
  • Zone 1 (Rural Low): 0.20–0.40
  • Zone 2 (Suburban): 0.40–1.00
  • Zone 3 (Urban Moderate): 1.00–5.00
  • Zone 4 (Urban High): 5.00–20.0
  • Zone 5 (Metropolitan): ≥ 20.0
