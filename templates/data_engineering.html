Phase 3 · Data Engineering

Data Engineering

Clean, transform, and prepare the dataset for the classification model.

Cleaning and Preparation
  • Validated that required columns are present and complete.
  • Retained valid high-radiance values because they represent real urban hotspots.
  • Converted balanced polygon records to point coordinates using centroid approximation.
  • Scaled proxy values to align with existing VIIRS radiance magnitudes.
Feature Engineering

The model uses derived features that capture radiance behavior and spatial context.

  • log_rad: log(1 + avg_rad) to reduce skewness.
  • rad_sq: avg_rad² to capture non-linear effects.
  • dist_bogota: distance to Bogotá centroid for urban influence.
  • lat and lon: geographic location.
Scaling and Normalization

Standard scaling was applied to numeric features to ensure consistent ranges and model stability.
