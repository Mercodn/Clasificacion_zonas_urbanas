Dataset Overview

The project uses VIIRS/SUOMI-NPP satellite data capturing nighttime radiance across Cundinamarca.

  • Total Records: {{ stats.total_points }}
  • Missing Values: 0 (complete dataset)
  • Geographic Coverage: Cundinamarca, Colombia
  • Satellite: VIIRS/SUOMI-NPP (DNB sensor)
  • Units: Radiance in nW/cm²/sr

Variable Analysis

  • latitude: Geographic coordinate (Y-axis)
  • longitude: Geographic coordinate (X-axis)
