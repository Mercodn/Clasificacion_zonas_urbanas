Dataset Overview

The prepared dataset contains 8,360 satellite observations from VIIRS. Each record includes geographic coordinates and average nighttime radiance values.

The dataset is suitable for the project because it includes more than 1,000 records, has real-world geographic context, and contains numeric variables for classification.

Data Quality
  • No missing values were found in the primary fields `avg_rad`, `lon`, or `lat`.
  • Coordinates are valid and geographically consistent with Cundinamarca.
  • Radiance values range from low rural values to high urban hotspots.
  • Outliers were identified and retained because they represent real urban lighting.
